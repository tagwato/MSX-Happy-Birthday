Programa em Basic para o microcomputador MSX que apresenta uma animação de Feliz Aniversário.
Utiliza o emulador webmsx.org.
O programa BASIC está neste repositório. 
Mas, para automatizar a carga, foi necessário previamente exportar para uma imagem de disco (também via WEBMSX).
O arquivo index.html mostra uma tela amigável com um botão "Abrir presente".
Isso chama o emulador em webmsx.org com os parâmetros adequados. 

O que enviar para o aniversariante é o link desse index.html, publicado como página web via GitHub Pages.

AQUI neste repositório foi necessário configurar assim:
Settings → Pages
Em Build and deployment:
Source: Deploy from a branch
Branch: main
Folder: / (root)

Salvar.

O GitHub então vai publicar o site. 

O link será (neste caso):
https://tagwato.github.io/MSX-Happy-Birthday

Esse é o link enviado para o aniversariante.
